# envoy-ai-python-sdk

Python SDK for building AI applications on [Envoy](https://github.com/envoyproxy/envoy).

This repository is in its initial setup; there is no release yet.

## Contributing

Contributions follow the [Envoy contributing guidelines](https://github.com/envoyproxy/envoy/blob/main/CONTRIBUTING.md).
All commits must be signed off (`git commit -s`) under the [DCO](https://developercertificate.org/).

Maintainers: [@envoyproxy/ai-python-sdk-maintainers](https://github.com/orgs/envoyproxy/teams/ai-python-sdk-maintainers).

## Security

Report security issues to [envoy-security@googlegroups.com](mailto:envoy-security@googlegroups.com), as described in the
[Envoy security policy](https://github.com/envoyproxy/envoy/blob/main/SECURITY.md), not in the public issue tracker.
